FAQ

Questions, answered

LumiQBrain is an AI lab building systems at the intersection of large language models, telecom and infrastructure — including LLMOS, ASK3GPP and TelecomOS — plus applied AI projects like Spendly.

LLMOS is an AI-native operating system layer that lets you interact with OS-level operations, automation, and intelligence using natural language, powered by an extensible agent framework.

ASK3GPP gives SME-grade 5G NR answers with machine-verified citations — every claim labeled spec-grounded or mechanism-inferred, checked against 9,500+ spec sections and 5,000+ tables. It uses structured knowledge compilation instead of vector RAG, which cuts hallucinated references and token usage by roughly 93%.

TelecomOS is zero-egress AI for the NOC — root-cause analysis, alarm-storm correlation, and human-gated self-healing for 5G networks, built on LLMOS so the model, reasoning, and telemetry all stay local, even air-gapped. Every remediation is propose → RBAC-approve → execute → verify, with a tamper-evident audit chain.

Mostly. Twelve projects — including LLMOS, ASK3GPP, Aegis and the Claude Token Optimizer — are open source on GitHub; fork them, file issues, or send a pull request. TelecomOS, Spendly and the projects in the workshop are private; email support@lumiqbrain.ai to request access.
